# HtmlDataset.php — HTML/XML File Parser

## Purpose

Thin `FileDataset` specialization that parses SMARTS HTML exports as XML via
`simplexml_load_file`, walking a fixed DOM path (`body.form.table.thead/tbody`) to extract
column headers and rows. Subclassed by `SMARTS\ParameterDataset`.

## Business Rules

| Rule ID | Description | Line | Confidence |
|---------|-------------|------|------------|
| R1 | Column names derived from `<thead><tr><th>`, normalized: lowercased, `/`→`_`, whitespace→`_` | 13-16 | [Confirmed] |
| R2 | Each `<tbody><tr>` becomes an assoc row keyed positionally by column index | 17-24 | [Confirmed] |
| R3 | Assumes a rigid `body > form > table > thead/tbody` structure — deviation breaks parsing | 14, 17 | [Inferred] |

## Security Findings

### SEC-4: Potential XXE via `simplexml_load_file` [Uncertain]
- **File:** src/Support/Dataset/HtmlDataset.php:12
- `simplexml_load_file` on caller-supplied file paths. On older libxml (< 2.9) external-entity
  expansion is enabled by default; a malicious SMARTS export could trigger XXE (local file
  disclosure / SSRF). Modern PHP/libxml disables this by default, so risk is version-dependent.
- **Category:** deprecated_api / version_hazard. Mitigate with `libxml_disable_entity_loader`
  or `LIBXML_NONET` if input provenance is not fully trusted.
